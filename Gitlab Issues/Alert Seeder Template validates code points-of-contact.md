### Alert Seeder Template validates code points-of-contact
##### Due on 

A new Alert must have:

* Valid `config/alerts.php['registry']` entry
* Valid definition version
* Valid `AlertType` enum case
* Valid `ScheduleType` -- only `Cron` is supported initially
* Valid `schedule_definition` (Cron expression)
* Valid Role IDs/Codes
