### Master Project – Master Project Management
##### Due on 

## Describe the new feature and what it will do briefly

Develop the user interface used to manage Master Projects.

Users should be able to:

* View all Master Projects.
* Create Master Projects.
* Edit Master Projects.
* Delete Master Projects.
* Enter and maintain comma-delimited CME order numbers.

The landing page should display a table of existing Master Projects. Selecting a Master Project opens the edit page where users maintain the project information.

---

## Access control and who will be using it?

Users with Master Project maintenance permissions.

---

## Data collection – is the data synthesized from other sources or created by the feature?

Creates and maintains:

* Master Project name
* Stored order-number string

Consumes backend APIs provided by the Core Services ticket.

---

## Release strategy? Outside of the code being put into production what else needs to happen?

Coordinate implementation with the Core Services APIs.

Validate create, edit, and delete workflows.
